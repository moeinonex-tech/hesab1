# دفتر حساب — PWA

این نسخه برای اجرا روی **GitHub Pages** آماده شده است.

## انتشار روی GitHub Pages

1. تمام فایل‌های این پوشه را داخل ریشه یک Repository در GitHub قرار دهید.
2. از مسیر **Settings → Pages**، گزینه **Deploy from a branch** را انتخاب کنید.
3. Branch را روی `main` و Folder را روی `/ (root)` بگذارید.
4. بعد از انتشار، آدرس GitHub Pages را با مرورگر باز کنید.
5. روی موبایل از گزینه **Add to Home Screen / افزودن به صفحه اصلی** استفاده کنید.

### نکته
برای نصب PWA باید سایت با HTTPS اجرا شود؛ GitHub Pages این مورد را فراهم می‌کند.

اطلاعات برنامه همچنان در `localStorage` مرورگر ذخیره می‌شود و قابلیت پشتیبان‌گیری داخلی خود برنامه حفظ شده است.
